## 🔧 Technical Notes

### **File Formats:**
- `.md` (Markdown) - Universal, editable
- `.html` (Web) - Opens in any browser
- `.pdf` (PDF) - Professional, read-only

### **Conversions:**
- Markdown → PDF: Use online tool or pandoc
- HTML → PDF: Browser print function
- Any → Email: Any format works

### **Accessibility:**
- HTML: No plugins needed, works offline
- Markdown: Plain text, very portable
- PDF: Professional format, great for printing

### **Storage:**
- Local: On company drive
- Cloud: Google Drive, OneDrive, Dropbox
- Web: Host on company website
- GitHub: Public repository
